    Diagnostic codes¶

    Machine output identifies a condition by diagnostics[].code; messages provide context and may become more precise. Automation should branch on the code. The index below is rebuilt from production Rust sources, so a documented code cannot exist without a corresponding implementation site.

    Start troubleshooting by symptom in the operations index.
