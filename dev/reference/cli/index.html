    CLI command tree¶

    This page is generated from the trajecta --help output produced by the current binary. Every frozen command is cross-checked against testdata/M5_CLI_CONTRACT.v1.json. run report is an implemented M5-A3 command that post-dates the frozen 35-command contract.

    Global rules¶

    • Global options may appear before or after a command.
    • Human output is the default. Use --format json for one envelope and --format jsonl for streams.
    • run waits in the foreground unless --detach is supplied.
    • job prune is dry-run only in this alpha release.
