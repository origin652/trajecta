    0.1.0-alpha.1¶

    0.1.0-alpha.1 是 Trajecta 的首个公开 Alpha 版本，提供从案例和已锁定气象资料到验证后轨迹结果的 完整本地流程。该版本适合功能评估、可重复科学工作流开发，以及在 受支持主机上进行早期业务运行。

    软件包¶

    平台 归档包 可执行文件
    Windows x86_64 trajecta-0.1.0-alpha.1-windows-x86_64.zip trajecta.exe
    Ubuntu 24.04 x86_64 trajecta-0.1.0-alpha.1-linux-x86_64.tar.gz trajecta

    两个归档包都包含原生气象运行时、ecCodes 定义和四个示例项目。 资料准备辅助工具与中英文离线快速入门也随包提供，供应链文件包括 SBOM 和第三方许可证 清单。CFSR 演示资料作为单独的下载资源提供，同一组文件可供两个平台的软件包使用。

    从 0.1.0-alpha.1 发布 下载归档包和对应 .sha256 文件，随后阅读安装与第一步。

    科学工作流¶

    该版本包含四条有完整文档的工作流：

    工作流 粒子群 示例项目
    区域填充水汽追踪 携带水汽质量的干空气区域填充 examples/domain-fill-cfsr
    定时释放 配置中声明的释放事件 examples/release-cfsr
    气团区域填充 表示有限体积干空气的粒子群 examples/air-mass-era5-pressure
    平流层臭氧 采用专用臭氧初始化规则的区域填充 examples/ozone-era5-hybrid

    所有粒子群共用球面中点 RK2 积分器和类型化气象查询路径。案例 可以沿物理时间正向或反向积分。有限区域会以稳定粒子 ID 记录边界生成和 终止。

    教程提供完整项目文件与命令序列。科学定义和生命周期见 概念。

    气象资料¶

    支持的气象资料系列如下：

    系列 垂直坐标 可用读取器
    CFSR 气压层 气压层 纯 Rust 与原生 ecCodes 路径
    ERA5 气压层 气压层 准备后资料的纯 Rust 与原生路径
    ERA5 混合模式层 137 个混合坐标模式层 准备后资料的纯 Rust 与原生路径

    内置资料配置将具体的源资料元数据映射为规范字段与派生物理量。资料尚未准备时， project data-plan 可以先报告所需文件；完成资料准备后，project finalize 创建资料锁。独立 Python 辅助工具可以下载和准备受支持的 CFSR 与 ERA5 资料，同时保持 CLI 命令树不变。

    包含四个文件的 CFSR 演示资源足以完成 15 分钟区域填充快速入门。ERA5 教程使用资料提供方 服务，并通过文档说明的 CDS 凭据渠道下载。

    项目与配置控制¶

    CLI 支持逐步完成本机和项目配置：

    • 初始化本机配置，并支持按选择器读取、修改和校验。
    • 初始化项目，并编辑带名称的案例与运行配置映射。
    • 在部分字段或资料待补时保留草稿项目。
    • 生成内容与顺序均可重复的资料计划。
    • 检查已准备的气象资料并生成资料锁。
    • 通过 doctor --deep 检查配置、文件系统、SQLite/WAL、资料锁和资料。
    • 文档与资料绑定完整后再完成项目定稿。

    项目文档路径必须留在项目根目录内。校验后的更新采用同目录临时文件和原子重命名；写入失败时 保留原文件。

    本地队列与进程模型¶

    运行由持久化本地守护进程、任务数据库和独立工作进程共同完成。前台模式会等待本次执行轮次 进入终态；run --detach 在任务写入持久化队列后返回，随后可以从另一个终端或会话继续观察。

    队列提供：

    • 明确的 CPU 槽位与内存预留；
    • 以先入先出（FIFO）为基础，并允许小任务有限度填补空闲资源；
    • 持久化任务状态，以及可供多个读者同时读取的事件流；
    • 宏步边界上的安全取消；
    • 强制取消后保留中断诊断文件；
    • 使用 PID 与进程启动标记完成守护进程重启恢复；
    • 在同一任务系列中创建新执行轮次的重跑；
    • 保留已经完成的执行轮次；
    • 用于审阅存储占用的只读清理计划。

    该版本的 job prune 不删除文件。队列操作和恢复步骤集中在操作指南与 运维。

    结果¶

    每个执行轮次使用独立结果目录。成功收尾后包含：

    文件 内容
    run-manifest.json 软件、解析输入、资料集、数值设置、生命周期、终止、质量、SQLite 与溯源摘要
    particles.sqlite 运行、粒子、质量、输出事件、采样状态和终止表
    provenance-bundle.json 采样字段对应的来源记录和转换过程
    run-report.md 由 run report 重新生成的人类可读摘要
    中断诊断与日志 当前执行轮次产生的运行诊断材料

    结果命令可以完成以下操作：

    • 查看运行清单与可用表数量；
    • 执行快速或完整验证；
    • 以可读文本、JSON 或 JSONL 流式读取指定粒子或全部粒子的轨迹；
    • 在固定路径生成 Markdown 报告。

    SQLite 是面向高级用法的只读接口。常用结果命令会先验证运行清单、数据库和溯源信息 之间的关系，再显示摘要。

    机器可读输出¶

    全局参数 --format json 返回一个 trajecta.cli-output/v1 JSON 响应对象。支持流式输出的命令可以使用 --format jsonl；每行是一个 trajecta.cli-stream-item/v1 对象，最后一行给出汇总。

    机器可读模式中的诊断使用稳定诊断码，用法错误保留进程退出码 2。完整命令树与格式规范 由参考手册自动生成。

    文档与示例¶

    发布手册提供英文和简体中文，并保持导航结构对应。内容包括：

    • 安装与源码构建路径。
    • 可执行的 15 分钟区域填充快速入门。
    • 四条完整科学教程。
    • 队列、事件、取消、重跑和恢复步骤。
    • 完整 CLI、schema、诊断码、退出码、结果与平台参考。
    • 带原始数据和可重建图表的科学与性能验证页面。
    • 构建、测试、软件包和文档贡献指南。

    静态站点使用带版本的 0.1.0-alpha.1 快照。持续修订进入 dev，直到下一次发布快照 建立。

    验证概览¶

    科学对比方法、可比较性分级、基准条件、计时表、资源测量和图表资料位于 验证。发行包测试矩阵覆盖三种资料系列与三种粒子群，并包含两个积分 方向、纯 Rust 与原生读取器路径，以及两个受支持平台。

    兼容说明¶

    这是首个产品发布，因此没有早期 Trajecta 项目格式需要迁移。以后评估其他 alpha 版本时， 可以随科学运行保留下列内容：

    归档包与校验和一起保存

    发布资源被复制或移动后，校验和仍可用于识别对应的软件包。

    • 原始归档包校验和与构建清单；
    • 项目索引、解析后的案例和解析后的运行配置；
    • 资料锁，以及源气象文件或散列；
    • 完整执行轮次目录；
    • 对应的版本化手册。

    文档与数据流 schema 各自携带版本标识。公开 Rust API 在 Alpha 期间面向贡献者。

    已知限制¶

    • 发布包面向 Windows x86_64 和 Ubuntu 24.04 x86_64。
    • 调度器只在本机运行，当前版本尚未提供远程主机或计算集群执行功能。
    • 插件加载尚未实现。
    • job prune 只报告清理预览，不移除文件。
    • 当前没有通用派生产品导出器；结果可通过轨迹流和只读 SQLite 读取。
    • 安全取消会关闭部分结果，之后不会继续同一个数值执行轮次。
    • 资料获取由独立辅助工具完成，下载后还需显式执行项目定稿。

    当前发行范围见 Alpha 限制。

    从这里开始¶

    新用户可以选择三种入口：

    1. 安装软件包并验证校验和。
    2. 从源码构建可执行文件。
    3. 运行区域填充快速入门。
