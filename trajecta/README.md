# Trajecta workspace

Trajecta is an open-source Lagrangian water-vapor tracking and atmospheric
trajectory framework. This directory contains the Rust workspace, product
packaging, executable examples, schemas, documentation sources, and validation
tools.

Start with the repository [README](../README.md) or build the bilingual manual
with:

```text
python -m pip install -r requirements-docs.txt
mkdocs build --strict
```

The published manual is available in [English](https://origin652.github.io/trajecta/)
and [简体中文](https://origin652.github.io/trajecta/zh-CN/). Historical plans,
execution reports, and model prompts are retained under `docs/engineering` and
do not enter the public site.
