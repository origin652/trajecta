# 气象资料与数值路径

科学计算链从不可变输入文档开始，最终得到等待定时输出的有序粒子批次。`trajecta-met` 负责
解释资料，`trajecta-core` 负责粒子生命周期。两者通过带类型的已准备气象查询
连接。

本页沿生产路径展开，并保留关键模块与类型名，方便贡献者直接定位源码。

## 输入绑定

生产运行接收已经解析的案例、运行配置，以及每个已选内置资料配置对应的资料锁。
项目在进入队列前通过定稿建立这组绑定。

资料锁固定运行期间不可变化的资料选择：

| 资料锁内容 | 运行时用途 |
| --- | --- |
| 内置资料配置与资料锁格式标识 | 选择约定的资料解释规则 |
| 有序文件清单与 SHA-256 | 发现文件被替换、截断或选择发生漂移 |
| 时间覆盖 | 确认起点、中点、释放、边界和输出查询都落在可插值的资料时段内 |
| 水平与垂直特征 | 将案例区域绑定到已经建立索引的网格和垂直层 |
| 能力要求集合 | 确认资料能够生成输送与粒子群所需字段 |
| 来源元数据 | 将资料集标识写入运行清单和溯源记录 |

`trajecta-case` 定义资料锁结构。生产加载器验证资料锁后，只访问其中声明的数据根目录。执行轮次启动后
不会临时寻找另一份更方便的文件。

## 运行配置编译与源资料清单

内置资料配置描述源记录如何生成规范字段。直接映射会指定具体的 GRIB 或 NetCDF
标识、源单位和时间含义，也可以列出顺序明确的备选来源。推导字段由带类型的计算图描述。

运行配置编译器会在粒子查询开始前完成静态检查：

- 计算图节点 ID 与输出名称没有重复；
- 依赖关系中没有环；
- 每个操作的单位与物理量纲一致；
- 数组形状与垂直交错布局相容；
- 操作只会在允许的资料帧、分块、垂直列或样本阶段执行；
- 所需的来源记录和能力要求都能解析。

操作集合是有名称的封闭集合，涵盖算术、单位换算、累计量差分、热力函数、混合坐标气压
构造和原生网格诊断。运行配置中的计算节点只能选择这些已登记操作，无法自行
访问文件。

来源清单主要依据元数据建立，文件名只作为其中一项信息。清单记录容器格式、有效时次、网格
描述、垂直拓扑、字段标识和资料集属性。运行配置中的精确匹配器据此选择记录。若出现重复候选
或不相容候选，加载器会返回诊断，不会采用隐式的“最后一个文件优先”规则。

## 资料帧选择

运行器会枚举模拟期间所有可能查询的物理时刻，包括运行端点、RK2 各阶段的中点、连续释放
时段、粒子群操作时刻和计划输出时刻。构建器随后选择一组连续的来源资料帧，使整个查询时段
都具备时间插值所需的前后帧。

查询恰好落在来源时间戳上时，推导字段仍可能需要相邻资料帧，例如累计量差分。所需
预热深度由能力依赖关系推导，因此计算累计量差分时会保留计算图所需的前序资料帧。

每个已选资料帧会经过以下处理：

1. 解码来源原生数组和有效性掩码。
2. 规范化单位，同时保留来源标识与质量检查。
3. 执行资料帧阶段和分块阶段的计算图节点。
4. 为气压层或混合坐标层资料构造垂直几何范围。
5. 将规范字段与溯源记录赋值存入 `RawMetFrame`。
6. 把资料帧放入有内存上限的 `FrameCache`，并为查询时刻组成 `PreparedWindow`。

水平拓扑保持来源资料的原生形式，准备阶段不会额外建立全局重网格副本。规则经纬网资料通过
对应的网格查询实现，风矢量插值会处理球面基向量的变化。

## 准备与执行

气象查询分为两个清晰阶段：

```text
MetEngine::prepare_for_domain(time, domain)
    -> PreparedWindow
PreparedWindow::prepare_transport_batch(plan, points, workspace)
    -> PreparedTransportBatch
PreparedTransportBatch::execute(execution_context, workspace)
    -> TransportOutput
```

准备阶段负责选择缓存中的资料帧、构造垂直列、计算水平落点，并固定所需的插值模板。执行阶段
只接收这些已经确定的结构，也拿不到文件读取器或资料提供方句柄，因此粒子采样期间不会打开
气象文件。

`BatchWorkspace` 保存可复用的暂存向量。调用方可在多个批次之间保留同一个工作区，减少重复
分配内存。执行上下文提供工作线程数；少于 256 个点的输送批次串行执行，较大的批次使用按线程数
复用的 Rayon 池。

缓存只承担查询准备和执行层面的复用：

| 缓存 | 键的核心内容 | 用途 |
| --- | --- | --- |
| 资料帧缓存 | 资料集与资料帧标识 | 在内存预算内保留解码后的规范字段 |
| 分块与垂直列缓存 | 字段、资料帧、空间支持和垂直请求 | 复用派生计算邻域和垂直列几何范围 |
| 边界插值模板会话 | 精确的路径查询支持 | 边界路径计算期间固定所需插值模板 |
| 最近一次精确输送查询 | 窗口标识、查询计划、区域、点数组与浮点位表示 | 只复用逐字节等价的输送请求 |

精确输送键包含资料帧窗口、时间权重、查询计划、垂直坐标和点值。粒子组、坐标、时刻或区域
只要有一项变化，都会生成新键。缓存命中时返回的类型化输出和溯源赋值，与重新执行同一精确
请求所得结果一致。

## 输送采样

积分器在海拔高度上查询三个输送组件：

- 东向风，单位为米每秒；
- 北向风，单位为米每秒；
- 几何垂直速度，单位为米每秒。

查询引擎先查找水平支持点，构造与来源资料相符的垂直列，应用近地层规则，再对两个相邻时次
的资料帧进行时间插值。风矢量插值会考虑球面基向量；标量字段和垂直速度则遵循字段注册表中
规定的插值与派生规则。

每个输出行同时包含数值、`SampleStatus`、字段质量检查、边界范围和溯源信息。状态能够区分
有效资料、地下采样、近地层限制、模式顶退出、区域退出与来源支持无效。积分器通过状态值判断
样本有效性，不依赖特殊浮点数作为标记。

与边界有关的状态可以交给连续边界路径处理。例如，预测位置已经离开区域或超过当前垂直支持
范围时，仍可能形成一条具有明确首个物理交点的路径段，并在边界正常终止。确实缺少输送支持
的粒子会记为 `invalid_meteorology` 异常。

## 球面中点 RK2

生产积分器 `Rk2Spherical` 位于 `trajecta-core/src/integrator`。粒子从时刻 \(t\) 出发，带符号
步为 \(\Delta t\) 时，会进行两次批次输送查询：

1. 在起始位置和时刻 \(t\) 查询速度。
2. 使用一半 \(\Delta t\) 构造中点位置。
3. 在中点位置和 \(t + \Delta t/2\) 查询速度。
4. 以中点速度从原始位置推进完整步。

水平位移在球面上计算，并规范化经度。垂直运动使用几何垂直速度。正向和反向运行共用一组
方程，通过 \(\Delta t\) 的符号区分方向；粒子年龄按每步的绝对时长增加。

在一个宏步内出生的粒子可以拥有不同的具体起始时刻。带时间分组的积分器会按稳定顺序合并
查询时刻相同的粒子，每个粒子只推进一次，终点统一落在宏步末端。反向积分会按时间倒序遍历
各组；同一批次内不能混合两个积分方向。

坐标出现非有限值、数值溢出或球面位移计算失败时，受影响的粒子会按数值失败终止。其余仍处于
活动状态的粒子继续执行，终态运行清单因而能够记录完整的粒子群结局。

## 边界顺序

积分器先返回尚未应用边界策略的候选批次，运行器随后检查前一状态与候选状态之间的连续路径。
边界处理由此保持独立，生命周期顺序不会随积分器的具体实现发生变化。

生产策略覆盖以下边界：

| 边界 | 处理结果 |
| --- | --- |
| 地表 | 按配置的地表策略反射，并受反射次数上限约束 |
| 模式顶 | 在首次与模式顶相交的位置终止 |
| 有限水平区域 | 在首次与区域边界相交的位置终止 |
| 全球经度 | 按周期边界处理经度 |

同一段路径可能与多条边界相交。此时，按顺序排列的路径段和交点比例共同确定最先发生的事件。
终止时间与位置都写在交点上，从而在两个积分方向中保持生命周期样本单调。

## 粒子群生命周期

`PopulationModel` 接口依次管理初始化、步前释放、公共积分器平流、平流后核算、边界维护和最终
收尾。这个顺序由运行器统一驱动，各种粒子群只实现相应阶段的专用规则。

### 释放型粒子群

释放型粒子群按配置的释放事件创建粒子。释放坐标需要解释气压、地形高度或模式层时，垂直坐标
解析器会查询气象资料。粒子加入积分组前，其生成时间、来源事件、质量和稳定 ID 已经确定。

### 区域填充干空气质量

区域填充根据所选原生网格和垂直几何范围划分有限的大气单元。有效层中的干空气质量由气象
状态计算，再按照案例设置分配给粒子。初始粒子组使用 `domain_initial` 来源。

有限区域的边界面层携带干空气通量。积分方向决定哪一侧的有符号通量属于流入。尚不足以生成
一个粒子的质量份额会作为余量留到后续宏步，不会在每次边界事件发生时直接舍入。新粒子带有
`domain_boundary` 来源、边界面 ID、生成时刻与稳定 ID。

### 平流层臭氧

臭氧型粒子群沿用区域填充输送和干空气质量核算，并采用专门的臭氧初始化规则。它的气象能力
要求中包含判断平流层来源和分配臭氧质量所需的字段。粒子群专用科学规则集中在初始化与质量
核算阶段，粒子运动仍使用公共输送查询和 RK2 实现。

## 确定性与溯源记录

并行查询开始前已经建立稳定顺序。粒子 ID、生成标识、输出事件序号和排序后的 SQLite 插入
顺序都不依赖 Rayon 任务的完成先后。相同解析输入使用不同工作线程数时，
实际运行时间可以变化，规范化科学内容应保持一致。

采样值与推导值都有对应的溯源信息。最终溯源信息文件将来源记录和转换过程独立于
粒子表记录，运行清单再绑定溯源信息与 SQLite 文件散列。终态处理详见[输出与运行时](runtime.md)。

## 检查科学路径修改

根据修改的规则选择检查范围：

| 修改 | 建议检查 |
| --- | --- |
| 运行配置映射或单位换算 | 运行配置编译测试与真实来源清单 |
| 读取器元数据或数组布局 | 覆盖所选时次和垂直层的原生/纯 Rust 差异测试 |
| 派生字段 | 计算图类型检查、质量与溯源断言、参考值 |
| 插值或垂直支持 | 区域内数值、各类边界状态、正反向回放 |
| 积分器 | 收敛案例、有符号时间对称性、极区与日界线、异常分类 |
| 边界 | 精确交点、事件顺序、反射次数上限、单调生命周期输出 |
| 区域填充 | 分层质量、余量结转、边界流入方向、稳定生成标识 |
| 查询性能 | 精确键审计、执行阶段 I/O 计数器、输出摘要、扩展性能矩阵 |

真实资料测试宜选择仍能覆盖生产读取器和相关拓扑的最小固定测试资料。性能修改完成后，还需确认
规范化输出与本次科学调整的预期一致。
