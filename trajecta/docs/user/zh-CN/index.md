# 使用 Trajecta 开展拉格朗日水汽追踪

Trajecta 在网格化气象场中追踪随气流运动的空气质点。每个积分步都会在粒子当前位置
读取风场、气压、温度和湿度等变量。轨迹积分器据此推进粒子，随后处理地表、模式顶和
水平边界，并在指定时刻写出粒子状态。正向计算从源区时刻向未来推进，反向计算则从
受体时刻向过去回溯。

同一套数值核心支持两类常见研究。释放试验在指定地点和时间创建粒子，可用于研究源区
物质的输送路径，也可用于计算受体轨迹。区域填充试验用一组粒子表示计算区域内的干空气
质量，并在粒子运动过程中跟踪水汽或臭氧。水汽来源与去向分析通常从区域填充工作流开始。

Trajecta 以命令行项目组织研究。案例（`Case`）保存能够随项目移动的科学设置；运行配置
（`RunProfile`）补充当前计算机上的资料路径、输出位置、读取器、线程数和内存预算。
运行前需要执行项目定稿命令 `project finalize`。该命令检查气象文件并生成资料锁
（`DatasetLock`）。工作进程随后接收已经展开并与资料锁绑定的输入，每次执行都写入独立目录。

## 适用的研究类型

| 研究类型 | Trajecta 创建的粒子群 | 常见问题 | 可用资料 |
|---|---|---|---|
| 区域填充水汽追踪 | 分布在全球或有限区域内的气团粒子 | 某区域内的水汽来自哪里，又从哪里离开？ | CFSR 或 ERA5 气压层资料 |
| 定时释放 | 由一个或多个时空源事件创建的粒子 | 源区释放的物质会输送到哪里？ | CFSR 或 ERA5 气压层资料 |
| 气团追踪 | 对有限区域内的干空气质量进行采样的粒子 | 气团如何进入区域、在区域内运动并最终离开？ | ERA5 气压层资料 |
| 平流层臭氧追踪 | 按 PV60 臭氧规则初始化的区域填充气团 | 选定时段内的平流层臭氧如何输送？ | ERA5 137 层混合坐标资料 |

`0.1.0-alpha.1` 中的四条工作流使用同一个球面 RK2 轨迹积分器。案例规定积分方向、
时间步长、边界策略、粒子群、随机种子和输出计划。运行配置说明如何读取气象资料，
并将源文件中的变量转换为积分器使用的标准物理量。

## 从案例配置到结果

```text
案例 + 运行配置 + 项目索引
                 │
                 ▼
            资料计划
                 │  准备或下载所需时次
                 ▼
          project finalize
                 │  检查文件并创建资料锁
                 ▼
         本地队列与工作进程
                 │  加载气象场，积分粒子，写出结果
                 ▼
              结果目录
```

气象资料尚未到齐时也可以先建立项目。`project data-plan` 会列出每个案例与运行配置组合所需的
物理时间范围、内置资料配置、读取能力、资料锁路径和资料目录。独立的 Python 资料助手先列出
下载请求，加入 `--execute` 后才开始下载。文件准备完成后，再执行 `project finalize` 检查资料并
创建资料锁。

`run` 默认在前台等待。加入 `--detach` 后，命令会在本地守护进程接收任务后返回。
守护进程持久保存队列状态，并按照 CPU 与内存资源池启动工作进程。机器重启后，已经
完成的执行轮次仍保持终态。`job rerun` 会在同一任务系列中创建新的执行轮次。

## 一次运行会产生什么

每次执行都会在运行配置指定的 `output_root` 下获得独立目录。`particles.sqlite` 保存
输出事件、粒子信息、按时间排列的粒子状态、随粒子携带的质量以及终止记录。
`run-manifest.json` 汇总本次执行使用的输入、数值设置、记录数量、质量统计和终态。
目录中还会保存工作进程实际采用的案例、运行配置，以及记录气象字段来源的
`provenance-bundle.json`。

常规读取从以下命令开始：

```text
trajecta result inspect RESULT
trajecta result verify RESULT --full
trajecta result trajectory RESULT --particle-id 0
trajecta run report --result RESULT
```

`result inspect` 可直接查看粒子数、输出时次、读取器、终止原因和主要文件位置。
`result trajectory` 按时间顺序输出指定粒子的记录。需要批量分析时，可以按照只读方式
访问 SQLite；相关表结构在参考手册中单独说明。
