# Domain-fill 水汽追踪原理

Domain filling 使用有限粒子 population 表示一个大气域。每个粒子携带由对应网格或质量
分层推导的干空气质量。气象比湿将干空气表示与轨迹沿途的水汽含量联系起来。

## 初始化

所选域和目标粒子数确定分层 population。冻结的随机维度分别选择质量层、经度、纬度和
气压位置。记录的随机种子保证这些选择可复现。

## 边界交换

执行期间，开放边界的流动可以产生流入粒子或终止流出粒子。Case 采用有限域边界策略时，
这些现象属于正常生命周期事件。质量账本在每个输出步记录初始质量、出生质量、终止质量
和最终活跃质量。

## 结果解释

发生边界交换时，粒子数可以变化。分析应同时考虑质量闭合、population reason、湿度状态
和空间采样。异常终止表示数值条件或输入质量问题，必须与正常物理流出分开统计。

Domain filling 提供采样表示。网格分辨率、粒子数、气象帧间隔、边界策略和输出 schedule
共同决定能够回答的科学问题。
