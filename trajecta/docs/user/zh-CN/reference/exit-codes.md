# 进程退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 命令成功，或后台任务已经持久化准入 |
| `1` | 应用失败、校验失败，或运行达到非成功终态 |
| `2` | 命令行用法或解析错误 |

运行相关命令需要同时检查机器 envelope 和进程状态。`ok` 表示命令本身是否完成；
存在 `run_success` 时，该字段表示所选运行是否成功。后台提交在准入后以 `0` 退出，
后续 worker 失败通过 `job status`、`job wait` 或 `job events` 观测。

信号、强制终止和操作系统加载失败可能产生表外平台退出值。此类情况应按 interrupted
执行处理，并保留任务数据库与 attempt 目录。
