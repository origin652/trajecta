# 科学验证方法

冻结的 M5-A5 对比使用官方 ERA5 hybrid 层资料和一小时平流 Case。两个程序均采用
600 秒输送步长、1,200 秒输出间隔、四个 CPU thread，以及相等的 10,000 或 50,000
粒子 population。

## 气象对齐

审计冻结源文件身份、查询点、物理时刻、单位、垂直解释和编码值。覆盖缺失、变量含义
不明确、异常非有限值或输入内容变化都会使审计失败。

## 内部硬门

每次 Trajecta 运行必须 Complete，异常粒子数为零，并通过以下项目：

- 生命周期与 population 核算；
- 有限值与质量检查；
- 质量账本闭合；
- 输出事件顺序；
- SQLite integrity 与终态 WAL；
- Provenance 与 canonical-output 身份；
- 重复运行确定性。

## 跨模型指标

对比在共同物理输出时刻计算集合质心、输送距离、水平离散、垂直均值和占用审计网格。
源采样随机数发生器与轨迹积分器不同，因此不建立 particle-ID crosswalk。集合差异属于
报告指标，不取代任一程序的内部硬门。

冻结重复运行的水平质心距离约为 61 至 277 m，离散宽度比为 1.0012 至 1.0051。这些
数值只描述当前合同与资料，不作为通用精度容差。
