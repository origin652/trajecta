# 验证证据规范

验证记录合同、冻结身份、执行条件、原始测量、派生汇总和验收门。只有合同中的全部硬门
通过时，结果才标记为 passed。

## 证据层级

| 层级 | 需要回答的问题 |
|---|---|
| 输入身份 | 是否使用预定源字节与 dataset profile |
| 气象资料 | Reader 是否提供对齐物理变量及查询覆盖 |
| 数值执行 | 生命周期、质量、有限值、边界和输出顺序是否有效 |
| 确定性 | 重复运行和不同 worker 设置是否保持规定摘要 |
| 产品 | Manifest、SQLite、WAL、provenance、报告和 CLI 行为是否有效 |
| 性能 | 在声明的主机与 workload 合同下测得什么结果 |
| 平台 | 每个受支持系统的 clean release package 是否通过 |

科学证据与产品证据共同保留。计时结果不能使科学硬门失败的运行获得通过。科学对比也不
表示配置、实现和输出产品可以互换。

当前跨模型证据只在 Validation 区域说明。普通用户页面依据 Trajecta 自身产品合同展开。
