# 0.1.0-alpha.1

该 alpha 建立 Trajecta 首个经过评估的产品面。

## 已包含

- 拉格朗日 release 与 domain-fill 大气轨迹执行。
- 水汽 air-mass 与 stratospheric-ozone population 工作流。
- CFSR pressure、ERA5 pressure 与 ERA5 hybrid 气象资料。
- 正向与反向轨迹。
- 支持前台和后台运行的持久化本地队列。
- 确定性 SQLite 结果，以及对应的 manifest 与 provenance。
- 结果验证、检查、轨迹读取和派生运行报告。
- Windows x86_64 与 Ubuntu 24.04 x86_64 产品安装包。
- 双语 MkDocs Material 手册与可执行示例。

## 已知限制

详见 [Alpha 限制](../reference/alpha.md)。当前不包含插件加载、远程调度、破坏性 prune
或通用结果导出器。
