# 0.1.0-alpha.1

This alpha establishes the first evaluated Trajecta product surface.

## Included

- Lagrangian release and domain-fill atmospheric trajectory execution.
- Water-vapor air-mass and stratospheric-ozone population workflows.
- CFSR pressure, ERA5 pressure, and ERA5 hybrid meteorology.
- Forward and backward trajectories.
- Durable local queue with foreground and detached operation.
- Deterministic SQLite results, manifests, provenance, verification, inspection,
  trajectory reading, and derived run reports.
- Windows x86_64 and Ubuntu 24.04 x86_64 product packages.
- Bilingual MkDocs Material manual and executable examples.

## Known limits

See [Alpha limits](../reference/alpha.md). Plugin loading, remote scheduling,
destructive pruning, and a general result exporter are not included.
