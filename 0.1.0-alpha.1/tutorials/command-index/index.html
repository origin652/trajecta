    Complete command index¶

    This index contains all 36 command forms available in the current Trajecta command-line program. Commands are grouped by the task they perform, so the page can be used as a menu after completing a tutorial. Optional and required arguments appear in each synopsis.

    Global options such as --config, --project, and --format may be placed before the command. The CLI command tree explains those options, argument placeholders, machine-readable output, and runtime behavior.

    Start with the shorter route

    The everyday command roadmap follows one project from setup through a verified result and includes the commands used most often.

    Machine configuration¶

    Command Use
    trajecta config init Create a machine configuration at the selected path
    trajecta config path Print the selected machine-configuration path
    trajecta config list List every configuration leaf and its value
    trajecta config get KEY Read one configuration selector
    trajecta config set KEY VALUE Validate and atomically update one selector
    trajecta config unset KEY Remove an optional selector
    trajecta config validate Validate the complete selected configuration

    Project preparation¶

    Command Use
    trajecta project init [PATH] --name NAME Create a project index and initial directory layout
    trajecta project status Report draft, configured, or finalized project state
    trajecta project show Show the resolved project index and document summary
    trajecta project get SELECTOR Read one project selector
    trajecta project set SELECTOR VALUE Validate and update one project selector
    trajecta project unset SELECTOR Remove an optional project selector
    trajecta project validate Validate the index and referenced Case and Profile documents
    trajecta project data-plan [--output PATH] Calculate deterministic dataset requirements and local status
    trajecta project finalize Inspect prepared data and atomically bind DatasetLocks

    Cases and meteorological data¶

    Command Use
    trajecta case validate PATH [--intent simulation|met-probe|migration] Validate a Case for a selected intent
    trajecta case resolve PATH Expand a Case into its resolved public document
    trajecta data inspect FILE Inspect one supported meteorological file
    trajecta data lock --root DIR --profile NAME --case FILE --output PATH [--replace] Build a DatasetLock from a Case, profile, and data root
    trajecta met probe --data-root DIR --profile NAME --time UNIX [options] Query selected meteorological points
    trajecta met replay --data-root DIR --profile NAME --input JSONL [options] Replay a JSONL meteorological query stream

    Environment checks and runs¶

    Command Use
    trajecta doctor [--deep] Check configuration, project, data, filesystem, and optional deep probes
    trajecta run (--project PATH --profile NAME | --case FILE --run-profile FILE) [--detach] Submit a project Profile or direct Case/Profile pair

    Job queue¶

    Command Use
    trajecta job list List the latest visible attempt for each job series
    trajecta job status JOB_ID Read the current snapshot for one job series
    trajecta job wait JOB_ID Wait for the current attempt to become terminal
    trajecta job events [JOB_ID] [--since SEQUENCE] [--follow] Read or follow durable queue events
    trajecta job cancel JOB_ID [--force] Request safe cancellation or force-stop the current attempt
    trajecta job rerun JOB_ID Create the next attempt in an existing series
    trajecta job forget JOB_ID Hide a terminal series from routine list output
    trajecta job prune Return the dry-run storage-prune plan

    Results and reports¶

    Command Use
    trajecta result inspect RESULT Summarize a run manifest, artifacts, and available SQLite counts
    trajecta result verify RESULT [--full] Run quick or full product verification
    trajecta result trajectory RESULT (--particle-id ID ... | --all) Stream trajectory rows for selected or all particles
    trajecta run report --result RESULT Create or refresh RESULT/run-report.md
