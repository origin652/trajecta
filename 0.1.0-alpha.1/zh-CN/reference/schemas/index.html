    JSON 与 JSONL schema¶

    Schema 文件是规范的机器可读定义。示例属于校验 fixture，不能代替 schema。Case 与 RunProfile 使用公开 YAML 文档合同，详见 Project、Case 与 Profile。

    产品 Schema 示例 顶层必填字段
    Trajecta machine configuration M5_CONFIG.schema.json M5_CONFIG.example.toml schema_version, default_reader_backend, daemon, resources, monitoring, profile_templates
    Trajecta project orchestration index M5_PROJECT_INDEX.schema.json M5_PROJECT_INDEX.example.yaml schema_version, name, cases, profiles
    Trajecta deterministic data plan M5_DATA_PLAN.schema.json M5_DATA_PLAN.example.json schema_version, project_sha256, requirements
    Trajecta single-result CLI envelope M5_CLI_OUTPUT.schema.json M5_CLI_OUTPUT.example.json schema_version, command, ok, data, diagnostics
    Trajecta JSONL stream item M5_CLI_STREAM_ITEM.schema.json M5_CLI_STREAM_ITEM.example.json schema_version, command, sequence, kind
    Trajecta durable job-attempt record M5_JOB_RECORD.schema.json M5_JOB_RECORD.example.json schema_version, job_series_id, run_id, attempt, state, input, resources, created_at
    Trajecta persistent job event M5_JOB_EVENT.schema.json M5_JOB_EVENT.example.json schema_version, sequence, emitted_at, job_series_id, run_id, attempt, kind, state
    Trajecta dry-run prune plan M5_PRUNE_PLAN.schema.json M5_PRUNE_PLAN.example.json schema_version, mode, delete_enabled, candidates
    Trajecta result inspection M5_RESULT_INSPECTION.schema.json M5_RESULT_INSPECTION.example.json schema_version, result_path, identity, lifecycle, software, inputs, execution, numerical, particles, quality, mass_ledger, artifacts, catalog
    Trajecta trajectory record M5_TRAJECTORY_RECORD.schema.json M5_TRAJECTORY_RECORD.example.json —
    Trajecta trajectory stream header M5_TRAJECTORY_STREAM.schema.json M5_TRAJECTORY_STREAM.example.json schema_version, job_series_id, run_id, attempt, status, run_success, selection
    Trajecta M4 run manifest M4_RUN_MANIFEST.schema.json — schema_version, job_series_id, attempt, run_id, case_name, status, started_at, software, inputs, execution, numerical, geometries, effective_outputs, sqlite, terminations, mass_ledger
    Trajecta M4 particle-state provenance bundle M4_PROVENANCE_BUNDLE.schema.json — schema_version, run_id, sqlite, record_hash_algorithm, records, field_sets, samples
    Trajecta product build manifest M5_BUILD_MANIFEST.schema.json M5_BUILD_MANIFEST.example.json schema_version, product, version, platform, source, build, archive, binary, sbom, license_inventory, native_components, payload

    Schema 版本独立标识磁盘或流格式，不随软件版本自动增加。M5.1 不引入新的 schema 版本。
