    CLI 命令树¶

    本页根据当前二进制的 trajecta --help 输出生成。全部命令都会与 testdata/M5_CLI_CONTRACT.v1.json 逐项核对；run report 也纳入同一检查。

    命令形式¶

    trajecta [GLOBAL OPTIONS] COMMAND [ARGUMENTS]

    全局参数可以位于命令前后。--config PATH 选择本机配置，进而确定本地守护进程端点和任务 数据库。--project PATH 为需要项目的命令选择项目根目录或项目索引。

    参数 含义
    --format human 人类可读输出，也是默认格式
    --format json 输出一个 trajecta.cli-output/v1 JSON 响应对象
    --format jsonl 支持流式输出的命令每行写一个 trajecta.cli-stream-item/v1 对象
    --json --format json 的别名
    --config PATH 显式指定本机配置，优先于环境变量和平台默认路径
    --project PATH 显式指定项目根目录或 trajecta-project.yaml
    -h、--help 显示命令帮助

    参数名称¶

    占位符 接受的值
    PATH、FILE、DIR 文件系统路径；项目文档路径必须留在项目根目录内
    KEY、SELECTOR 点分配置选择器或项目选择器
    JOB_ID 任务准入返回的任务系列 ID
    RESULT 结果命令接受的任务系列 ID、运行 ID 或结果目录路径
    UNIX 以秒表示的 UTC Unix 时间戳整数
    JSONL 每行一个 JSON 对象的文件路径；部分气象命令还接受 - 作为标准输入或输出

    运行行为¶

    • run 默认在前台等待；--detach 在任务持久化接收后返回。
    • 前台运行会等待执行轮次进入终态。另一个终端可通过 job status、job wait 或 job events 重新连接。
    • job events、气象数据流和轨迹输出可以使用 JSONL，最后一项为汇总。
    • 当前 Alpha 版本的 job prune 只返回预览计划，不提供删除或应用参数。
    • 机器可读模式中的应用错误与成功命令使用相同响应格式，Shell 脚本仍可读取进程退出码。

    命令¶

    命令概要 用途 机器输出
    config init 在所选路径创建本机配置 单次响应
    config path 显示当前本机配置路径 单次响应
    config list 列出所有最末级配置字段及其值 单次响应
    config get KEY 读取一个配置选择器 单次响应
    config set KEY VALUE 校验并原子更新一个配置选择器 单次响应
    config unset KEY 移除一个可选配置选择器 单次响应
    config validate 校验完整的所选配置 单次响应
    project init [PATH] --name NAME 创建项目索引和初始目录结构 单次响应
    project status 显示项目的草稿、已配置或已定稿状态 单次响应
    project show 显示解析后的项目索引与文档摘要 单次响应
    project get SELECTOR 读取一个项目选择器 单次响应
    project set SELECTOR VALUE 校验并更新一个项目选择器 单次响应
    project unset SELECTOR 移除一个可选项目选择器 单次响应
    project validate 校验项目索引及其引用的案例与运行配置 单次响应
    project data-plan [--output PATH] 计算可重复生成的资料需求及其本地状态 单次响应
    project finalize 检查已准备资料，并以原子更新方式绑定资料锁 单次响应
    case validate PATH [--intent simulation|met-probe|migration] 按指定用途校验案例 单次响应
    case resolve PATH 将案例展开为解析后的公开文档 单次响应
    data inspect FILE 检查一个受支持的气象资料文件 单次响应
    data lock --root DIR --profile NAME --case FILE --output PATH [--replace] 根据案例、资料配置和资料根目录构建资料锁 单次响应
    met probe --data-root DIR --profile NAME --time UNIX [options] 查询指定气象点 可使用 JSONL
    met replay --data-root DIR --profile NAME --input JSONL [options] 重放 JSONL 气象查询流 可使用 JSONL
    doctor [--deep] 检查配置、项目、资料和文件系统；按需执行深入检查 单次响应
    run (--project PATH --profile NAME | --case FILE --run-profile FILE) [--detach] 提交项目运行配置，或直接提交案例与运行配置 可使用 JSONL
    job list 列出各任务系列的最新可见执行轮次 单次响应
    job status JOB_ID 读取一个任务系列的当前快照 单次响应
    job wait JOB_ID 等待当前执行轮次进入终态 可使用 JSONL
    job events [JOB_ID] [--since SEQUENCE] [--follow] 读取或跟随持久化队列事件 可使用 JSONL
    job cancel JOB_ID [--force] 安全取消或强制停止当前执行轮次 单次响应
    job rerun JOB_ID 在现有任务系列中创建下一执行轮次 单次响应
    job forget JOB_ID 从日常列表隐藏终态任务系列 单次响应
    job prune 返回只读存储清理计划 单次响应
    result inspect RESULT 汇总运行清单、产物和可用 SQLite 数量 单次响应
    result verify RESULT [--full] 执行快速或完整结果验证 单次响应
    result trajectory RESULT (--particle-id ID ... | --all) 流式读取指定粒子或全部粒子的轨迹记录 可使用 JSONL
    run report --result RESULT 创建或刷新 RESULT/run-report.md 单次响应

    完整操作顺序见项目准备、 队列运行与结果读取。

    二进制原始帮助¶

    trajecta — Trajecta command-line interface

Usage:
  trajecta run (--project PATH --profile NAME | --case FILE --run-profile FILE) [--detach]
  trajecta COMMAND [arguments]

Commands:
  config init
  config path
  config list
  config get KEY
  config set KEY VALUE
  config unset KEY
  config validate
  project init [PATH] --name NAME
  project status
  project show
  project get SELECTOR
  project set SELECTOR VALUE
  project unset SELECTOR
  project validate
  project data-plan [--output PATH]
  project finalize
  case validate PATH [--intent simulation|met-probe|migration]
  case resolve PATH
  data inspect FILE
  data lock --root DIR --profile NAME --case FILE --output PATH [--replace]
  met probe --data-root DIR --profile NAME --time UNIX [options]
  met replay --data-root DIR --profile NAME --input JSONL [options]
  doctor [--deep]
  run (--project PATH --profile NAME | --case FILE --run-profile FILE) [--detach]
  job list
  job status JOB_ID
  job wait JOB_ID
  job events [JOB_ID] [--since SEQUENCE] [--follow]
  job cancel JOB_ID [--force]
  job rerun JOB_ID
  job forget JOB_ID
  job prune
  result inspect RESULT
  result verify RESULT [--full]
  result trajectory RESULT (--particle-id ID ... | --all)
  run report --result RESULT

met probe options:
  --points PATH       JSONL points (`-` = stdin); default single Europe sample
  --backend rust|native
  --coverage-start UNIX --coverage-end UNIX
  --allow-estimated   --explain  --summary|--no-summary
  --output PATH       JSONL output (`-` = stdout)

met replay options:
  --input PATH        JSONL stream (`-` = stdin)
  --output PATH       JSONL stream (`-` = stdout)
  --backend rust|native
  --coverage-start UNIX --coverage-end UNIX
  --allow-estimated   --explain  --summary|--no-summary

Global:
  --format human|json|jsonl
  --json              alias for --format json
  --config PATH       explicit machine configuration
  --project PATH      explicit project root or index
  -h, --help          show this help
