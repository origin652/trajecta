    0.1.0-alpha.1¶

    0.1.0-alpha.1 是 Trajecta 首个产品 release，提供从 Case 与 locked meteorological dataset 到 verified trajectory result 的完整本地流程。该版本适合功能评估、可重复科学工作流开发，以及在 受支持主机上进行早期业务运行。

    软件包¶

    平台 Archive Executable
    Windows x86_64 trajecta-0.1.0-alpha.1-windows-x86_64.zip trajecta.exe
    Ubuntu 24.04 x86_64 trajecta-0.1.0-alpha.1-linux-x86_64.tar.gz trajecta

    两个 archive 都包含 native meteorological runtime、ecCodes definition 和四个 example project。 资料准备 helper 与中英文离线快速入门也随包提供，供应链文件包括 SBOM 和 third-party license inventory。CFSR 演示资料作为独立 release asset 发布，同一组文件可供两个平台软件包使用。

    从 0.1.0-alpha.1 release 下载 archive 和对应 .sha256 文件，随后阅读安装与第一步。

    科学工作流¶

    该版本包含四条有完整文档的工作流：

    工作流 Population Example project
    Domain-fill moisture 携带水汽质量的 dry-air domain filling examples/domain-fill-cfsr
    Release trajectory 配置的 release event examples/release-cfsr
    Air-mass domain fill Dry-air finite-volume population examples/air-mass-era5-pressure
    Stratospheric ozone 使用 ozone-specific seeding 的 domain filling examples/ozone-era5-hybrid

    所有 population 共用 spherical midpoint RK2 integrator 和 typed meteorological query path。Case 可以沿物理时间正向或反向积分。有限 domain 会以 stable particle identity 记录 boundary birth 和 termination。

    教程提供完整 project file 与 command sequence。科学定义和生命周期见 概念。

    气象资料¶

    支持的产品资料家族为：

    Family 垂直坐标 Product reader
    CFSR pressure Pressure level Pure Rust 与 native ecCodes path
    ERA5 pressure Pressure level Prepared product 的 Pure Rust 与 native path
    ERA5 hybrid 137 个 hybrid model level Prepared product 的 Pure Rust 与 native path

    Dataset Profile 将准确 source metadata 映射为 canonical field 与 derived quantity。资料尚未存在时， project data-plan 可以先报告所需文件；完成资料准备后，project finalize 创建 DatasetLock。独立 Python helper 能获取受支持的 CFSR 与 ERA5 requirement，同时保持 CLI command tree 不变。

    包含四个文件的 CFSR 演示 asset 足以完成 15 分钟 domain-fill quickstart。ERA5 tutorial 使用 provider 资料，并通过文档中的 CDS credential channel 下载。

    Project 与配置控制¶

    CLI 支持渐进式 machine/project setup：

    • 初始化 machine configuration，并支持 selector-level 读取、修改和校验。
    • 初始化 project，并编辑具名 Case/Profile mapping。
    • 在部分 field 或 data 待补时保留 draft project。
    • 生成 deterministic data plan。
    • Inspect 并 lock 已准备的 meteorological data。
    • 通过 doctor --deep 检查配置、filesystem、SQLite/WAL、lock 和 data。
    • Document 与 data binding 完整后再 finalize project。

    Project document path 受 project root containment 约束。Validated update 失败时，temporary-file 与 atomic-rename write 会保留原文件。

    本地队列与进程模型¶

    运行通过 durable local daemon、job catalog 和独立 worker process 执行。Foreground mode 等待 submitted attempt。run --detach 在任务进入持久化队列后返回，另一个 terminal 或 session 可以 继续观察。

    队列提供：

    • 明确的 CPU-slot 与 memory reservation；
    • 带 bounded small-job backfill 的 FIFO scheduling；
    • Persistent job status 与 fan-out event stream；
    • Macro-step boundary 上的 safe cancellation；
    • 保留 forensic file 的 force cancellation；
    • 使用 PID 与 process-start identity 的 daemon restart recovery；
    • 在同一 job series 中创建新 attempt 的 rerun；
    • Completed attempt preservation；
    • 用于存储审阅的 dry-run prune plan。

    该版本的 job prune 不删除文件。队列操作和恢复步骤集中在操作指南与 运维。

    结果¶

    每个 attempt 使用独立 result directory。成功收尾后包含：

    产品 内容
    run-manifest.json Software、resolved input、dataset、numerical、lifecycle、termination、mass、SQLite 与 provenance identity
    particles.sqlite Run、particle、mass、output event、sampled state 和 termination table
    provenance-bundle.json Sampled field 对应的 source-record 与 transformation assignment
    run-report.md 由 run report 重新生成的 human-readable summary
    Forensic/log entry 存在时的 attempt-specific runtime material

    Result command 可以完成以下操作：

    • 查看 manifest 与可用 table count；
    • 执行 quick 或 full verification；
    • 以 human text、JSON 或 JSONL 流式读取 selected/all particle trajectory；
    • 在固定路径生成 Markdown report。

    SQLite 是高级 read-only interface。Primary result command 会先验证 manifest、database 和 provenance 之间的关系，再显示 summary。

    Machine output¶

    Global --format json 返回一个 trajecta.cli-output/v1 envelope。Stream-capable command 可以使用 --format jsonl；每行是一个 trajecta.cli-stream-item/v1 object，最后一行是 summary item。

    Machine-mode diagnostic 使用 stable code，usage error 保留 process exit code 2。完整命令树与 format schema 由参考手册自动生成。

    文档与示例¶

    Release manual 提供英文和简体中文，并保持 navigation 对应。内容包括：

    • 安装与 source-build 路径。
    • 可执行的 15 分钟 domain-fill quickstart。
    • 四条完整科学 tutorial。
    • Queue、event、cancellation、rerun 和 recovery procedure。
    • 完整 CLI、schema、diagnostic、exit-code、result 与 platform reference。
    • 带 raw data 和可重建 chart 的 scientific/performance validation page。
    • Build、test、package 和 documentation contributor guide。

    Static site 使用带版本的 0.1.0-alpha.1 snapshot。持续修订进入 dev，直到下一次 release snapshot 建立。

    验证概览¶

    Scientific comparison、comparability class、benchmark condition、timing table、resource measurement 和 chart data 位于验证。Archive product matrix 覆盖三种资料家族、三种 population、两个方向、pure/native reader path 和两个正式操作系统。

    兼容说明¶

    这是首个产品 release，因此没有早期 Trajecta project format 需要迁移。以后评估其他 alpha 版本时， 可以随科学运行保留下列内容：

    Archive 与 checksum 一起保存

    Release asset 被复制或移动后，checksum 仍可用于识别准确软件包。

    • 原始 archive checksum 与 build manifest；
    • Project index、resolved Case 和 resolved RunProfile；
    • DatasetLock，以及 source meteorological file 或 hash；
    • 完整 attempt directory；
    • 对应的 versioned manual。

    Document 与 stream schema 各自携带 version identifier。Public Rust API 在 alpha 期间面向贡献者。

    已知限制¶

    • 产品软件包面向 Windows x86_64 和 Ubuntu 24.04 x86_64。
    • Scheduler 运行在本机，没有 remote 或 cluster backend。
    • Plugin loading 尚未实现。
    • Prune command 只报告 dry-run plan，不移除文件。
    • 当前没有通用 derived-product exporter；可以使用 trajectory streaming 和 read-only SQLite。
    • Safe cancellation 会关闭 partial result，之后不会继续同一个 numerical attempt。
    • Dataset retrieval 是显式 helper step，完成后还需执行 project finalization。

    完整产品边界见 Alpha 限制。

    从这里开始¶

    新用户可以选择三种入口：

    1. 安装软件包并验证 checksum。
    2. 从源码构建 binary。
    3. 运行 domain-fill quickstart。
